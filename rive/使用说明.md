# 银潮 · 玻璃海浪（Rive 原生重制版）

`银潮-玻璃海浪.riv` 是可供 Rive Runtime 加载的二进制动画文件，包含海浪与控制面板。使用 Rive 官方 CLI 1.8.0 生成，不包含运行时脚本。

- 主画板：`Silver Tide`，1600 × 1000。
- 默认状态机：`Ocean Controls`。
- 数据模型：`OceanControls`，默认实例 `Default`。
- 海浪：8 秒循环，960 条原生矢量光丝及倒影。
- 字体已嵌入；无需额外加载字体或图片。

## 与网页版的区别

这是针对 Rive 格式重新制作的版本，不是 HTML/WebGL 的无损转换。海浪使用原物理轨迹采样后的矢量路径和时间轴，保留流动与回落的视觉方向；三维视角拖动、实时随机物理、WebGL 水面折射以及 CSS 背景模糊没有原样封装。倒影和玻璃材质为 Rive 原生效果近似。

滑块、预设、暂停/继续、倒影开关、面板收起和帮助说明在文件内处理。音频采集、文件选择、全屏和截图属于宿主应用的职责；对应按钮发送事件，不会在独立 `.riv` 中直接调用操作系统。

## 音乐驱动

宿主应用分析音乐后，写入默认数据模型的 `speed`、`trail`、`density`。波浪高度 `amplitude` 和粒子亮度 `glow` 保持手动设置。

| 参数 | 默认值 | 范围 | 用途 |
|---|---:|---:|---|
| amplitude | 1 | 0.2–2 | 波浪高度 |
| speed | 1 | 0.05–2 | 播放速度 |
| trail | 0.92 | 0–1 | 光丝长度 |
| density | 1 | 0.15–1.5 | 光丝密度 |
| glow | 1.2 | 0.3–2 | 手动亮度 |
| ripples | 0.8 | 0–2 | 倒影柔化程度 |
| reflectivity | 1.25 | 0–1.8 | 倒影强度 |
| reflection | 1 | 0 或 1 | 倒影开关 |
| panelVisible | 1 | 0 或 1 | 面板显示 |
| helpVisible | 0 | 0 或 1 | 帮助说明 |
| playing | true | 布尔值 | 播放与暂停 |

宿主事件：`connectSystemAudio`、`openAudioFile`、`saveFrame`、`fullscreen`、`splash`。其中 `splash` 也需要宿主实现额外的一次喷溅；文件内的海浪循环持续播放。

集成时启用自动数据绑定，并运行 `Ocean Controls`。使用支持 Rive Renderer 的运行时，以显示羽化发光效果。官方文档：https://rive.app/docs/runtimes/data-binding

## 源项目

`scene.rml`、`rive.yaml`、`assets/` 是 Rive CLI 源项目。安装官方 CLI 后可运行：

```powershell
rive . --verify
rive .
rive . --once
```

`.riv` 是运行时格式，不是 Rive 编辑器的 `.rev` 源文件。如需 `.rev`，在自己的 Rive 账号登录后执行 `rive . --once --rev=silver-tide.rev`。

字体使用 Noto Sans SC 的静态子集，许可证见 `assets/OFL.txt`。网页版保持原样，未部署此次 Rive 重制内容。
